# ayedigitalmkt

Landing page simple para presentar paquetes mensuales de community management y estrategia digital, con comentarios de referencia y marcas/emprendimientos.

Los testimonios están marcados como textos de muestra y las marcas ficticias como ejemplos. Reemplazalos o validalos antes de publicar.

## Cómo abrirla en Visual Studio Code

1. Abrí la carpeta `ayedigitalmkt`.
2. Abrí `index.html` con Live Server o directamente en el navegador.
3. En `script.js`, reemplazá:

```js
const WHATSAPP_NUMBER = "549XXXXXXXXXX";
```

por tu número real, sin el signo `+`, espacios ni guiones.

Ejemplo de formato argentino:

```js
const WHATSAPP_NUMBER = "54911XXXXXXXX";
```

La web utiliza HTML5, CSS3 y JavaScript vanilla. No requiere instalación de dependencias ni framework.
